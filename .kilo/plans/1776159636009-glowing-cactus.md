# Redesign Navbar Effect

The user feels the current glowing effect in the Navbar is too overwhelming. The goal is to maintain the "floating", "bold", and "no frame" aesthetic while replacing the intense glow with a cleaner, more professional effect.

## Proposed Changes

### 1. Remove Excessive Glowing
- Remove all `drop-shadow` classes from the logo (`Duy.`).
- Remove `drop-shadow` from the navigation links (both active and hover states).
- Remove the glow from the active state indicator dot.

### 2. Refine "Bold & Floating" Aesthetic
- Keep `font-black` for the logo and `font-bold` for the links to maintain the bold look.
- Preserve the `fixed` position and lack of background/border to keep it floating.

### 3. Implement a Cleaner Interaction Model
- **Logo**: High-contrast white text with the accent dot. Remove the pulse animation if it feels too "much", or keep it very subtle.
- **Navigation Links**:
    - **Inactive**: `text-gray-400` with a smooth transition to `text-white` on hover.
    - **Active**: `text-white` with a sharp, small accent dot underneath.
- **Mobile Menu**: Transition from glowing text to a clean, high-contrast white/gray list.

## Execution Steps

1.  Modify `src/components/Navbar.tsx`:
    -   Update the logo `Link` classes.
    -   Update the `navLinks.map` loop to replace `drop-shadow` with clean color transitions.
    -   Update the active state indicator dot classes.
    -   Update the mobile menu links to remove glowing effects.
